# Страница конкурса — вёрстка для Tilda

`konkurs.html` — готовый самодостаточный блок: разметка + изолированные стили
(все классы с префиксом `.kn`, конфликтов с темой Tilda нет).

## Как поставить на страницу

1. Tilda → нужная страница → **Библиотека блоков → Другое → T123** («HTML-код»).
2. Открыть «Контент», вставить **всё содержимое** `konkurs.html`.
3. Сразу под T123 добавить **нативный блок формы Tilda (FR-серия)** — чтобы
   заявки уходили в «Мои заявки» / CRM / на почту. В настройках блока формы
   (Настройки → Ещё → ID контейнера) указать `form-block`.
4. Опубликовать.

## Что заменить

Всё, что в фигурных скобках `{{...}}` — плейсхолдеры:

| Плейсхолдер | Что подставить |
|---|---|
| `{{URL_ФОНОВОЙ_КАРТИНКИ}}` | ссылка на изображение из Медиа-библиотеки Tilda |
| `{{Название конкурса}}`, `{{Организатор}}` | реальные названия |
| даты, возраст, номинации, суммы призов | из положения о конкурсе |
| `{{ССЫЛКА_НА_PDF}}` | файл положения, загруженный в Tilda |
| `{{EMAIL}}`, `{{ТЕЛЕФОН_БЕЗ_ПРОБЕЛОВ}}` | контакты оргкомитета |

Найти все разом: поиск по `{{` в редакторе.

## Что заложено в юзабилити

- **Главное действие видно сразу** — кнопка «Подать заявку» в первом экране,
  повтор в CTA-блоке и липкая кнопка внизу экрана на телефоне.
- **Ответы до прокрутки** — блок «коротко о главном»: кто, что, до какого
  числа, какие награды. Пользователь понимает, подходит ли ему конкурс,
  за 5 секунд.
- **Требования разделены на «примем / не примем»** — это основная причина
  отказов, поэтому вынесено в отдельный контрастный блок.
- **Сроки — таймлайном**, текущий этап подсвечен.
- **FAQ на `<details>`** — раскрывается без JS, работает и в мобильной Tilda.
- Адаптив: 4 → 2 → 1 колонка; кнопки во всю ширину на телефоне;
  учтён `prefers-reduced-motion` и `safe-area-inset` для iPhone.

## Палитра

Чернильно-синий `#1a2238`, приглушённое золото `#a67c3d`, бумага `#fbf8f2`.
Заголовки — Cormorant Garamond, текст — Inter. Меняется в одном месте:
CSS-переменные в начале блока `.kn { --ink: ...; }`.
